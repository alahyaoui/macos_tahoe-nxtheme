# MacOS Tahoe v1.0.0

A light, frosted-glass Nintendo Switch theme inspired by macOS Tahoe, for the
**Basic White** system theme (firmware 23.5.0). Unofficial; not affiliated with Apple or Nintendo.

## What's included
- **Home**: glass dock with rounded-square buttons in macOS proportions, labels above it and an
  indicator dot under News; menu-bar style avatars (top-left) and Wi-Fi / battery / clock (top-right);
  rounded game tiles and a rounded "All software" button
- **All software & Groups**: rounded tiles, cards and thumbnails
- **Player select**: login-screen style user cards centred on an aurora wallpaper
- **Settings, User page, News, Lock screen**: rounded list rows, capsule buttons, macOS-blue cursor,
  no separator lines
- **Boot logo**: optional bitten-pear hekate splash (`bootloader/bootlogo.bmp`)

## Install
1. In NXThemes Installer, remove any installed theme and reboot.
2. Copy the seven `.nxtheme` files to `/themes` on the SD card.
3. Install all seven (Home also updates shared dialogs and the cursor) and reboot.

Set the system theme to **Basic White** (Settings > Themes).
