# Themezer listing (copy/paste)

**Title:** MacOS Tahoe

**Description:**
Unofficial light, frosted-glass theme inspired by macOS Tahoe, for the Basic White system theme
(tested on firmware 23.5.0). Glass dock with rounded-square buttons in macOS proportions, menu-bar
style status area, rounded game tiles and group cards, login-style user select, rounded list rows,
capsule buttons and a macOS-blue cursor everywhere. Original artwork and layouts; not affiliated with
Apple or Nintendo. License: CC BY-NC-SA 4.0. Source and boot logo:
https://github.com/alahyaoui/macos_tahoe-nxtheme

**Tags:** macos, tahoe, apple, glass, liquid glass, light, white, minimal, dock, pastel
